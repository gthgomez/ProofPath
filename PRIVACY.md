# ProofPath Privacy Policy

> **Play Store URL placeholder:** `TODO_PRIVACY_URL`

## Summary

ProofPath is a **local-only** career-learning app. Your progress stays on your device.

## Data collection

- **No account required.** The app does not create user accounts or collect personal identifiers on our servers.
- **No progress sync.** Lesson progress, quiz attempts, evidence, and weekly plans are not uploaded to remote servers by this app.
- **No third-party analytics or ads** in the configuration described here.

## Data storage

Career path selection, lesson completion, quiz attempts, portfolio evidence, review queue state, and weekly plan progress are stored locally in an on-device SQLite database (`careerforge.db` via expo-sqlite).

## Code Lab sandbox

- In-app Python and JavaScript lesson runners execute in a sandbox with **`allowNetwork: false`**.
- User-written lesson code cannot open outbound network connections from the sandbox policy enforced by the app.

## Erase data

You can erase all local data from **Settings → Reset progress**. This permanently deletes on-device profile, progress, reviews, evidence, and weekly reports and cannot be undone.
